FIX DAD'S LAPTOP  -  one step
=============================

On Dad's laptop:

  1. Plug in this USB.
  2. Open this FIX-DAD folder.
  3. Double-click  FIX-DAD.bat
  4. Click "Yes" on the blue admin prompt.
  5. Wait until it says DONE (about a minute). A fresh Firefox opens by itself.

That's it. It turns remote access back on, installs the fixed extension,
clears the pile of stuck Firefox windows, and reopens Firefox clean.
Claude finishes and double-checks everything remotely afterward.

(A log file named fix-dad-<date>.log is written in this folder - leave it,
it lets Claude see exactly what happened.)
