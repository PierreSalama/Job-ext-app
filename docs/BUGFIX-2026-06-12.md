# JAT v11 — Hardening pass (2026-06-12)

Adversarial multi-agent review of the whole v11 codebase (8 dimension finders,
every finding independently verified against the cited code). 27 real bugs
confirmed; 26 fixed, 1 dismissed as a non-issue. All unit tests + a live
end-to-end smoke pass after the fixes.

## High severity

| Area | Bug | Fix |
|---|---|---|
| `app/src/main.js` | Server-start failure still created the window/tray → a live-looking app with no backend | Close DB and quit cleanly on `startServer` failure |
| `app/src/main.js` + `db.js` | DB use-after-`close()` could crash main on shutdown race | `will-quit` clears DB-touching timers *before* `db.close()`; `run/get/all/exec` throw a clean "database is closed"; `kvGet/kvSet` no-op when closed |
| `app/src/ai/ollama.js` | `spawnTried` never reset → Ollama only ever auto-started once per app lifetime | Re-armed in `status()` (runs before every generate-chain + on the 30s timer) |
| `extension/content/loader.js` | `jat11.reboot` handler didn't `return true` → response port could close before async reboot ran | Resolve engine, then respond, `return true` |
| `extension/content/executor.js` | EEO/demographic fields auto-filled from profile without review | New `NEVER_AUTOFILL_RX` (race/gender/disability/veteran/criminal/pronoun) filtered out of fills entirely; work-auth/sponsorship/citizenship still fill (profile's purpose) |
| `extension/content/executor.js` | `new File()` not in try/catch; silent resume-attach failure → could submit without a résumé | File ctor guarded; caller pauses the run (`awaiting_input`) when a résumé was needed but couldn't attach |
| `extension/app/app.js` | Inline `onclick="location.reload()"` did a hard reload (lost token/SSE) | `data-refresh` + `navigate()` soft refresh |
| `app/src/ai/provider.js` | `statusAll` cache served stale "unavailable" for 30s after a fix | `valid` flag set only after a complete fresh probe; invalidated on auth error |
| `extension/content/lib/dom.js` | `qsa` host-scan cap == result cap → deep shadow roots dropped on big pages (Workday) | Decoupled: scan up to 30k hosts, cap results at 6k separately |

## Medium / low

- `provider.js` — error `aiLog` now records the real model, not `''`.
- `app/src/db.js` — **reentrant transactions** (only the outermost issues BEGIN/COMMIT/ROLLBACK), so `patchJob` and the server's job+event writes are now atomic and safely composable; `PRAGMA user_version` no longer template-interpolated.
- `app/src/server.js` — `POST`/`PATCH /jobs` wrap upsert+event in one transaction (no orphan/missing events); document raw-download validates the path stays under `userData/documents` (traversal guard).
- `extension/background.js` — `contextMenus.removeAll()` before create (idempotent across updates); base64 of the résumé is chunked through `btoa` (no multi-MB string).
- `extension/content/detector.js` — fire-and-forget `persist()` calls now `.catch`; Apply-click on an unrecognized page only accepts with a real job signal (kills signup-page false positives); success re-scan ticker is armed on Apply / stopped on submit + `pagehide` (no lifetime-long interval); step-advance handler de-raced.
- `extension/content/autofill.js` — `<select>` matching prefers exact, then case-insensitive, then *longest* substring (so "5" picks "5-10 years", not "3-5 years").
- `extension/content/signals/forms.js` — contact-form detection checks the whole form body, not just a heading.
- `extension/content/executor.js` — re-verifies the advance button is still clickable right before clicking; validates the AI answer's shape (typed `answer`+`confidence`) before trusting it.

## Dismissed (verified non-issue)

- `server.js` token compare "timing leak": the length check short-circuits `timingSafeEqual` (safe), and the token length (64) is a public constant — nothing to leak.

## UI overhaul (same pass)

- **Popup** rebuilt into a mission-control panel: live connection + queue, a "this page" card showing what JAT detects on the active tab (with stage + save state), live stats (tracked / this week / needs-review), auto-apply state, a recent-captures list (click → dashboard), plus the existing pair/update/download affordances. New `getPageState()` on the detector + a `jat11.page-state` message power the page card.
- **Capture panel** gained a stage progress bar and a collapse-to-pill control (persisted per tab) — even less intrusive, reinforcing silent mode.
- **Dashboard** gained shimmer loading skeletons (replacing the bare "Loading"), a subtle per-view fade-in, and the kanban card/drag class names were corrected to match the CSS (titles/company now styled; drag-over + dragging states animate). All motion respects `prefers-reduced-motion`.
